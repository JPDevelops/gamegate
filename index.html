How it works

01 · DETECT

Knows when you're gaming

A tiny agent watches your processes and recognizes games automatically — Steam, Epic, GOG, Riot, Xbox — no configuration needed.

02 · HOLD

Holds the noise

Incoming Gmail, Slack, and Discord messages are captured, prioritized by deterministic rules (optionally AI-assisted), and queued — not delivered.

03 · BREAK THROUGH

Emergencies still reach you

Anything truly urgent pops a small overlay over your game — visible, audible, never focus-stealing.

04 · DIGEST

One clean catch-up

Quit the game and get a single summary: session length, what needs action, what can wait. Exactly once, never duplicated.

Built like a real service

Engineering

FastAPI · SQLite behind a repository layer · idempotent ingestion · pure-function routing engine · 95 offline tests · CI on every commit.

Resilient by design

Server down? The agent retries. Notifier closed? Messages queue. AI provider dead? Deterministic rules take over. Nothing is lost, nothing duplicates.

Private by default

Self-hosted — your messages live in one SQLite file on your own server. Read-only Gmail scope. Token-authenticated API. No third party sees anything.

Get running (bring your own server)

GameGate is self-hosted: the Windows app talks to your GameGate server — a Raspberry Pi, an old laptop, or any small Linux VM works. Two pieces, ~10 minutes:

# 1 · Server (any Linux box)
git clone https://github.com/JPDevelops/gamegate.git && cd gamegate
python3 -m venv .venv && source .venv/bin/activate && pip install -e .
cp .env.example .env   # set GAMEGATE_API_TOKEN
uvicorn app.main:app --host 127.0.0.1 --port 8000

# 2 · Windows PC
#    Download GameGate.exe, put config.json next to it
#    (server address + the same token), double-click.

Full deployment guide (systemd, Nginx, integrations): the docs.
